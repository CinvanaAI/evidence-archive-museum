# Origin

This repository is a public, generic extraction of the CinvanaAI Chronicle dashboard built during a private 2026 archive investigation.

The original dashboard treated a rendered page as a derived view over atomic records, topic groups, a timeline, dispositions, questions, and source evidence. It exposed counts and source coverage so the page could not quietly invent unsupported narrative.

The public extraction preserves the useful idea—an offline evidence museum with explicit eras, lineage, dispositions, and source-addressed records—while replacing the private Markdown/register conventions with a small documented JSON contract. Personal records, testimony, credentials, investigation state, machine paths, and generated private pages were not copied.
