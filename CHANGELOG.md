# Changes

## 1.1.0

Topic cards open their exact member records. Record search can stay within that topic, with an explicit route back to all records; empty searches explain how to recover. Navigation and search fields have accessible labels and visible keyboard focus.

The example now traces a record through the four input files. Counts describe structural validation and adjacency references precisely; the reader does not imply that it fetched or verified source evidence. The data format and CLI remain compatible.
